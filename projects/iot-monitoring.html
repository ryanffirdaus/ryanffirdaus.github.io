About This Project

A web-based monitoring system that collects and displays data from IoT devices in real-time. The platform handles device communication through MQTT protocol and provides features like automated alerts, data logging, and analytics.

Built to be scalable and handle thousands of data points while keeping response times low.

Key Features

  • Real-time data from multiple IoT devices
  • MQTT-based device communication
  • Automated alert system
  • Historical data and analytics
  • Docker deployment ready

Technical Details

Backend Laravel, Node.js
Protocol MQTT
Cache Redis
Deployment Docker
